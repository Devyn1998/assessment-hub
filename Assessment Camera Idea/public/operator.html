"Measure on Live Video" taps points right on the feed — no photo saved. "Capture Photo to Measure" freezes a frame first if you want a saved record. Either way, it first scans for a person in frame to auto-scale from (assumed height shown below, adjustable) — if found, just tap the two points you want to measure. If no one's in frame, it falls back to tapping the 4 corners of a reference object (a door works great and is usually already in frame) for a more precise, angle-corrected measurement. Tapped a point in the wrong spot? Hit "Undo Last Point" (or Ctrl/Cmd+Z) — it works on the live feed and on a frozen photo. Switching rooms above never ends this session.
